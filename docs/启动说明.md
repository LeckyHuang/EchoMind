# 语录管理后台 - 启动说明

## 服务地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 后端 API | http://localhost:8000 | Python FastAPI |
| 前端页面 | http://localhost:8888 | 纯静态 HTML |
| API 文档 | http://localhost:8000/docs | Swagger UI |

---

## 快速启动

### 1. 启动后端

```bash
cd ~/Desktop/工作交付物/voicerecorder

# 首次启动（如数据库未初始化）
python3 init_admin.py

# 启动服务
python3 main.py
```

### 2. 启动前端

```bash
# 新开一个终端
cd ~/Desktop/工作交付物/voicerecorder/frontend
python3 -m http.server 8888
```

### 3. 访问

打开浏览器：
- 前端：http://localhost:8888/login.html
- 默认账号：`admin` / `密码：123456`

## 配置说明

编辑 `voicerecorder/.env`：

```env
# ASR 服务商（mock=模拟模式，doubao/qwen/minimax=真实接口）
ASR_PROVIDER=doubao

# LLM 服务商（mock=模拟模式，minimax/kimi/qwen=真实接口）
LLM_PROVIDER=minimax
```

> ⚠️ 默认是 mock 模式（无需 API Key），如需真实 ASR/LLM 能力，填入对应的 API Key。

## 管理员操作

### 创建新用户

1. 登录 admin 账号
2. 进入「用户管理」
3. 点击「新建用户」
4. 填入用户名/邮箱/角色（admin 或 user）
5. 新用户默认密码：`123456`

### 重置用户密码

1. 进入「用户管理」
2. 点击对应用户的「重置密码」

### 管理 Prompt 模板

1. 进入「Prompt 管理」
2. 点击「编辑」修改 Prompt 内容
3. 使用「预览」查看效果
4. 设为「激活」后，新分析将使用该模板

### 配置清理周期

1. 进入「设置」
2. 修改「文件过期时间」（小时）
3. 修改「清理周期」（cron 表达式，如 `0 3 * * *` 表示每天凌晨3点）

## 部署到服务器

### 方式一：直接运行（开发/小规模）

```bash
nohup python3 main.py > app.log 2>&1 &
```

### 方式二：systemd 服务（生产推荐）

```ini
[Unit]
Description=语录智能录音后端
After=network.target

[Service]
User=你的用户名
WorkingDirectory=/path/to/voicerecorder
ExecStart=/usr/bin/python3 main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

### Nginx 反向代理（可选）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
    }

    location /uploads {
        alias /path/to/voicerecorder/uploads;
        expires 7d;
    }
}
```

## 状态说明

| 状态 | 说明 |
|------|------|
| pending | 等待处理 |
| processing | 处理中 |
| completed | 完成 |
| failed | 失败 |

录音上传后会自动进入 `completed`（如果 ASR+LLM 成功）或 `failed`（如果失败）。
